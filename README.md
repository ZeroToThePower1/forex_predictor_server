# Forex Predictor API

Advanced Forex prediction system using economic events and machine learning.

## Features
- Multi-currency pair support (EUR/USD, GBP/USD, etc.)
- Event-based prediction with XGBoost models
- Probability ensemble system
- Prediction history tracking
- RESTful API with FastAPI
- Web dashboard included

## Quick Start

### Local Development
```bash
# Clone repository
git clone https://github.com/yourusername/forex-predictor.git
cd forex-predictor

# Install dependencies
pip install -r requirements.txt

# Run server
python server.py
